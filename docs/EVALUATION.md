# Evaluation checklist

Use a manually labelled, India-relevant validation set. Do not convert a single model
confidence into an accuracy percentage.

## Perception

- Precision and recall per hazard class
- mAP50 and mAP50–95
- Day/night/rain performance slices
- Small, blurred and partially occluded object slices

## Temporal confirmation

Record false alerts on the same video before and after filtering:

```text
false-alert reduction (%) = (raw FP - filtered FP) / raw FP × 100
```

Also measure additional confirmation latency introduced by the filter.

## Edge performance

- Named device and operating mode
- Input resolution and frame-skip setting
- Median and P95 inference latency
- End-to-end FPS, CPU/RAM and temperature
- Source and exported model size
- Accuracy change after INT8 quantization
- Captured camera FPS versus analytics attempts per second
- Stale frames deliberately dropped by the bounded edge buffer
- Per-capability target rate, achieved attempts, failures and mean/max latency
- Estimated single-worker utilization from measured latency, clearly labelled as an estimate
- Thermal throttling and offline-queue recovery during a continuous field run

## ANPR

- Exact plate-match rate
- Character accuracy
- Day/night, motion-blur and viewing-angle slices
- Percentage marked for human review

## Bandwidth

Use actual file sizes generated by `bandwidth_demo.py`. State whether short incident clips
are included in the edge payload.
